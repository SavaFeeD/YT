# Иконка YT

Все итоговые визуальные ассеты находятся в `public/`:

- `app-icon.svg` — векторный мастер: градиентная папка с белой музыкальной нотой.
- `app-icon.png` — прозрачный PNG 1024×1024.
- `favicon.ico` — Windows ICO с независимыми рендерами 16, 20, 24, 32, 40, 48, 64, 128 и 256 px.

Исходный маленький PNG пользователя использован как визуальный референс.
Для поиска формы использован встроенный imagegen; финальный мастер заново построен
в SVG, чтобы избежать размытия и неровных прозрачных краёв растровых эскизов.

Спецификация / prompt: «Чёткая градиентная папка с выступом слева сверху,
цвета от бирюзового через синий к фиолетовому, крупная белая музыкальная нота,
простая геометрия, прозрачный фон, без букв, теней, свечения и декоративных деталей;
узнаваемость при 16–48 px».

Для повторного экспорта установите `resvg-py` в отдельное окружение инструментов и
запустите `python scripts/build_icons.py`. Для обычной сборки YT эта зависимость не нужна:
готовый `favicon.ico` уже включён в проект. Исходные цвета и пути задаются в SVG,
каждый размер ICO рендерится напрямую из вектора, а не увеличивается из маленького PNG.
