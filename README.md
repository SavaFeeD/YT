# YT 1.0

Настольная библиотека музыки, MP3-плеер и загрузчик плейлистов YouTube для Windows x64.
Скачанная музыка воспроизводится без интернета. Интерфейс рассчитан на 16:9,
поддерживает обычное, развёрнутое и полноэкранное окно.

## Установка

В **Releases** репозитория скачайте `YT-Setup.exe`. Для запуска без установки
распакуйте `YT-<версия>-windows-x64.zip` целиком и откройте `YT\YT.exe`.
Python, Node.js и FFmpeg пользователю устанавливать не нужно.

Обновление с 0.x сохраняет папку установки, настройки, музыку и архив загрузок.
Версия берётся из одного файла — `VERSION`.

## Возможности

- **Моя музыка:** MP3 из выбранной папки и подпапок, поиск, названия и исполнители из ID3.
- **Плеер:** воспроизведение/пауза, предыдущий и следующий трек, перемотка, громкость и mute.
- **Перемешать:** случайный порядок без повторов в одном проходе. После последнего трека
  воспроизведение останавливается; ▶ начинает новый проход. Ручной выбор и переход назад
  позволяют повторить трек намеренно. Обновление библиотеки не сбрасывает очередь.
- **Загрузки:** плейлисты YouTube/YouTube Music в MP3, 128–320 кбит/с, от 1 до 6 треков
  одновременно, отдельный прогресс, суммарная скорость и отмена очереди.
- Новые загрузки появляются в библиотеке автоматически, а музыка продолжает играть при
  переключении разделов. Поиск фильтрует отображение, не меняя очередь.

Двойной щелчок по локальному треку запускает его. Кнопка **Папка загрузки** возвращает
библиотеку к папке сохранения. **F11** — полный экран, **Esc** — обычное окно.
Проверяемые размеры интерфейса: 1920×1080 и 1280×720.

Скачанные записи учитываются в `.yt-archive.txt` выбранной папки. Для повторного
скачивания удалённого MP3 удалите соответствующую строку из архива либо выберите
другую папку. Остановка может дождаться текущего сетевого запроса или FFmpeg.
Повышение битрейта не улучшает качество исходной записи. Сохраняйте материалы,
на скачивание которых у вас есть разрешение.

## Быстрый старт разработчика

Рекомендуется Windows x64 и Python 3.13 (минимум 3.11).

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe -m pip install --no-deps --no-build-isolation -e .
.\.venv\Scripts\python.exe -m yt
```

`preview.cmd` открывает то же приложение. После изменения кода перезапустите окно.
Для предпросмотра конкретного плейлиста без автоматического скачивания:

```powershell
preview.cmd --playlist "ССЫЛКА_НА_ПЛЕЙЛИСТ"
```

`app.py` оставлен как короткий совместимый запускатель. Основной код находится в пакете `src/yt`.
Зависимости объявлены в `pyproject.toml`, точное окружение разработки/сборки — в `requirements.lock.txt`.


## Проверки

```powershell
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m ruff format --check .
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m yt --smoke-test
```

Тесты не обращаются к YouTube. GUI-сценарии запускаются в отдельных процессах Windows.
Быстрый прогон без рабочего стола: `python -m pytest -q -m "not desktop"`.
Отдельная ручная сетевая проверка первого видео плейлиста:

```powershell
.\.venv\Scripts\python.exe scripts/check_download.py "ССЫЛКА_НА_ПЛЕЙЛИСТ"
```

Тестовый MP3 сохраняется в `test-download/`, исключённой из Git.

## Сборка

Дополнительно нужны Node.js 22+ в PATH и Inno Setup 6/7. Компилятор находится в
`tools\Inno`, PATH или стандартной папке установки. Для другого пути задайте
`INNO_SETUP_COMPILER`, указывающий на `ISCC.exe`.

```powershell
release.cmd
```

Скрипт устанавливает зафиксированные зависимости, подключает пакет, собирает EXE
и установщик. Для автоматизации: `release.cmd --no-pause`.
Перед сборкой закройте копию `dist\YT\YT.exe`, если она запущена.

Результаты:

- `dist\YT\YT.exe` — приложение с зависимостями;
- `release\YT-Setup.exe` — установщик для текущего пользователя;
- `release\YT-<версия>-windows-x64.zip` — portable;
- `release\SHA256SUMS.txt` — SHA-256 установщика и ZIP.

Python wheel отдельно: `python -m build --wheel`. Ассеты берутся из `public/`;
иконка содержит девять размеров 16–256 px. [Исходник и экспорт иконки](public/icon-design.md).
Рабочие файлы сборки находятся в `build/` и не попадают в Git.

## Релизы GitHub

**CI** проверяет стиль, тесты, старт окна и сборку wheel при push в `main` и pull request.
**Release** по тегу собирает Windows-приложение, проверяет EXE/MP3-декодер и публикует
установщик, portable ZIP и SHA-256. Тег обязан совпадать с `VERSION`.

После коммита изменений и успешных проверок для версии 1.0.0:

```powershell
git push origin main
git tag -a v1.0.0 -m "YT 1.0.0"
git push origin v1.0.0
```

Ручной запуск **Actions → Release → Run workflow** создаёт скачиваемые артефакты
без публикации релиза. Они хранятся 14 дней. Используется встроенный `GITHUB_TOKEN`,
отдельный токен в Secrets не нужен; Actions должны быть разрешены в репозитории.

## Данные и диагностика

- Настройки: `%LOCALAPPDATA%\YT\settings.json`.
- Журнал: `%LOCALAPPDATA%\YT\logs\yt.log` с ротацией.
- Музыка и архив: выбранная пользователем папка.

Удаление приложения сохраняет музыку. Для работы YouTube может потребоваться обновить
yt-dlp и пересобрать приложение. Основные зависимости: [yt-dlp](https://github.com/yt-dlp/yt-dlp),
[FFmpeg](https://ffmpeg.org/), [pygame-ce](https://pyga.me/), [Pillow](https://python-pillow.org/),
[Mutagen](https://mutagen.readthedocs.io/), [PyInstaller](https://pyinstaller.org/)
и [Inno Setup](https://jrsoftware.org/inno-setup).
